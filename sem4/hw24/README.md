## 24-0 

Реализуйте `Python`-модуль **matrix** с функцией *dot*, которая выполняет алгебраическое умножение двух квадратных вещественных матриц заданного размера, представленных в виде списка списков.

В случае, если в качестве аргументов переданы матрицы, в которых количество строк или столбцов меньше указанного размера, то оставшаяся часть матриц дополняется нулями. Если больше указанного размера - то лишние строки или столбцы не используются.

Пример использования модуля:
```
import matrix

A = [[1,2], [3,4]]
B = [[1,2], [3,4]]

R = matrix.dot(2, A, B)
print(R)
```

На сервер нужно отпарвить только исходный файл, который будет скомпилирован и слинкован с нужными опциями.


## 24-1

Реализуйте `Python`-модуль **aes256**, который выполняет декодирование данных шифром `AES-256-CBC`.

Модуль должен содержать две функции: *decode* для декодирования и *set_default_password*, который устанавливает пароль по умолчанию, чтобы его было не обязательно передавать в качестве аргумента.

В случае, если декодирование не возможно, то необходимо кидать исключение с некоторым осмысленным текстом ошибки.

Более точные сигнатуры:
```
def decode(encrypted: bytes(), password: str() = None) -> bytes:
    pass
    
def set_default_password(password: str()) -> None:
    pass
```
    
Пример использования модуля:
```
import aes256            
            
with open("data.aes", "rb") as f:
    encoded = f.read()

decoded = aes256.decode(encoded, "qwerty")
print(decoded)

aes256.set_default_password("qwerty")
print(aes256.decode(encoded))

try:
    aes256.decode(encoded, "wrong password")
except BaseException as e:
    print("Can't decode: {}".format(e))
``` 

Используйте библиотеку *OpenSSL/LibreSSL*, которую вы ранее использовали для похожего домашнего задания.

На сервер нужно отпарвить только исходный файл, который будет скомпилирован и слинкован с нужными опциями.
